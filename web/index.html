bviz

The bviz app, compiled to WebAssembly. Files open in this tab and are never uploaded.

Drop Bazel build files here: a profile, a build event stream, an execution log, or query, cquery and aquery output.

Recording these files, and linking to them

Capture a build with bviz bazelrc's flags, or name them yourself: --profile=command.profile.gz --build_event_binary_file=build.bep --execution_log_compact_file=exec.binpb.zst, plus --experimental_profile_include_target_label. Graphs come from bazel aquery|cquery|query --output=streamed_proto.

A link opens files over HTTP directly, one parameter per flag, for example ?profile=https://example.com/command.profile.gz&bep=https://example.com/build.bep. The server must allow this page to fetch them (CORS).
